# Sprint2

Sprint 2 del bootcamp **Bécalos Techno Ready Workshop/Bootcamp**, enfocado en Machine Learning.

## Contenido

Este repositorio incluye una copia del proyecto [handson-ml](https://github.com/ageron/handson-ml) de Aurélien Géron (código y notebooks de la 1ª edición del libro *Hands-On Machine Learning with Scikit-Learn and TensorFlow*), usado como material de estudio y práctica para el sprint.

```
Sprint2/
└── handson-ml-master/
    ├── 01_the_machine_learning_landscape.ipynb
    ├── 02_end_to_end_machine_learning_project.ipynb
    ├── 03_classification.ipynb
    ├── ...                              # notebooks por tema (SVM, árboles, redes neuronales, etc.)
    ├── datasets/                          # datasets usados en los notebooks (housing, lifesat)
    ├── requirements.txt                   # dependencias de Python para correr los notebooks
    └── README.md                          # README original del proyecto handson-ml
```

> Nota: todo el contenido de `handson-ml-master/` pertenece al proyecto original de Aurélien Géron ([ageron/handson-ml](https://github.com/ageron/handson-ml)); no es trabajo propio del autor de este repositorio.

## Cómo usarlo

Ver las instrucciones de instalación en [handson-ml-master/INSTALL.md](handson-ml-master/INSTALL.md), o instalar las dependencias directamente:

```bash
cd handson-ml-master
pip install -r requirements.txt
jupyter notebook
```
